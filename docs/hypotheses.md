# 検証仮説・指標・合格ライン

PoCで答えを出したい問いは2つ。

1. **そもそも求める人がいるか（主目的）**
2. **お金を払う意思があるか（できれば）**

合格ラインは仮の値。D7のプレオープンの結果を見て、一般公開前に一度見直す。

## 指標
| # | 問い | 指標 | 計測方法 | 仮の合格ライン |
|---|---|---|---|---|
| H1 | 来たいと思うか | 広告・告知→入店率 | PostHog：`page_view` → `room_joined`（流入元で分ける。**知人以外の流入で判断する**） | 30%以上 |
| H2 | 敷居は低いか | 入店→1回以上発言 | `room_joined` → `chat_sent`（1回目） | 50%以上 |
| H3 | 居心地はいいか | 平均滞在時間 | `room_joined` → `room_left` の差 | 10分以上 |
| H4 | また来るか | 別の日に再来訪した割合 | PostHogのリテンション（端末IDで判定） | 20%以上 |
| H4' | 常連が生まれるか | 3日以上来た人数 | 同上 | 10人以上 |
| H5 | 求められているか | 事前登録数（正式版のお知らせ） | フォームの件数 | 50件以上 |
| H6 | 払うか | 常連パス（月480円・準備中）ボタンのクリック率 | `paywall_clicked` / 入店者数 | 5%以上 |
| H6' | 本当に払うか（任意） | キープボトル（500円）の購入数 | Stripe | 5件以上 |
| — | 営業時間外の需要 | 営業時間外に来た人数 | `closed_page_view` | 参考値 |

## 判断の読み方
| 結果 | 意味 | 次の一手 |
|---|---|---|
| H1が低い | コンセプトか訴求が刺さっていない | LPの訴求・ターゲットを変えて再テスト |
| H1は高いがH2が低い | 「敷居が低い」仮説がNG | 発言のきっかけ（お題、エモート、AI店主）を強化 |
| H2は高いがH3/H4が低い | 来るが居着かない（人の密度か中身の問題） | 営業時間の集中、イベント、常連づくり |
| H4とH6が合格 | **需要あり＋支払い意思あり** | MVPへGo（事業計画の実行1年目） |

## イベント定義（D6で実装済み：`apps/client/src/analytics.ts`）
**発言の本文は送らない**（ログを残さない約束を守るため）。

| イベント | いつ | プロパティ |
|---|---|---|
| `page_view` | 画面を開いた | 流入元（utm_*） |
| `room_joined` | 入店した | 店内人数 |
| `chat_sent` | 発言した | 文字数・何回目か（本文は送らない） |
| `emote_sent` | 反応（わかる／笑／へぇ）を付けた | 種類 |
| `seat_taken` | 席に座った | 席の種類（カウンター／テーブル） |
| `room_left` | 退店した | 滞在秒数 |
| `paywall_clicked` | 常連パスを押した | — |
| `paywall_answered` | 「いくらなら入りますか？」に答えた | 選んだ答え |
| `waitlist_clicked` | 事前登録フォームを開いた | どこから（常連パス／準備中画面） |
| `invite_clicked` | 「誘う」で共有・コピーした | 方法（share／copy） |
| `report_sent` | 通報した | 店主かどうか |
| `closed_page_view` | 営業時間外に来た | 入店禁止が有効か |

事前登録の件数（H5）は、フォーム側の回答数で数える（`waitlist_clicked` は開いた数）。
招待から来た人は、`page_view` の `utm_source=invite` で数える。

## 定性調査
ユーザー5人に、1人15分程度インタビューする。
- なぜ来たか
- 他のSNSやメタバースではなくここである理由
- また来るか、来ないならなぜか
- いくらなら払うか、何にお金を払いたいか
