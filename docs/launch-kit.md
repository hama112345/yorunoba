# 一般公開（D10）の告知キット

告知文の下書きと、どこから来た人かを数えるためのURLの付け方。そのまま使っても、言い回しを変えても良い。
数字（利用者数・満足度など）は、実績が出るまで書かない。

## 前提（推定したもの）
- 載せる場所：X（旧Twitter）の投稿、noteの記事、Discordのお知らせ、少額広告（XやInstagramの見出し30字以内）。
- トーン：親しみ・少し夜っぽい。煽らない。
- 言えること（事実）：URLを開くだけ・登録なし／テキストだけ（声も顔も出さない）／毎晩21〜24時だけ開く／発言は数秒で消えて保存されない／ドット絵の居酒屋／18歳以上／AI店員と店主が見回る。

## 言うこと
- **本音**：仕事終わりに、誰かと少しだけ話したい。でも人を呼び出すほどでもないし、通話は重いし、SNSは反応を待つのが疲れる。
- **メッセージ**：ヨルノバは、URLを開くだけで入れる、テキストだけの夜の居酒屋。ふらっと寄って、ひとことだけでもいい。

**サブコピー**（見出しの下に1行）
- URLを開くだけ。登録なし・テキストだけの居酒屋が、毎晩21時に開きます。
- 話した言葉は数秒で消えて、どこにも残りません。

## 変化球（視野を広げる用）
- 「今夜の話し相手、まだ決まってない人へ。」（呼びかけ）
- 「のれんをくぐるのに、靴はいりません。」（たとえ）

## 候補プール（散らかした案。選び直しに使う）
- 生活の一場面：帰りの電車で開く居酒屋／パジャマで入れる大衆酒場／風呂上がりの一杯に、隣の席を
- 否定・禁止：無理に話さなくていい店／盛り上げなくていい夜／自己紹介はいりません
- 問いかけ：今日、誰かと話しましたか？／今夜は誰と飲みますか？
- 時間軸：21時に開いて、24時に閉まる店／ラストオーダーは23時45分
- 音・リズム：ゆるく飲んで、ゆるく話す／ふらっと寄って、ひとことだけ
- 独白：「ひとりで飲むけど、ひとりじゃない」
- 機能：URLだけで入れる居酒屋／登録なし、今夜から

## noteの記事（たたき）
- タイトル案：「家に着いてからの、もう一軒。テキストだけの居酒屋を開けました」
- 構成
  1. なぜ作ったか（仕事終わりに誰かと少し話したい、でも通話もSNSも重い）
  2. どんな店か（スクリーンショット2〜3枚：店内・乾杯・お題）
  3. 遊び方（のれんをくぐる→床をタップで歩く→席に座る→ひとこと話す・🍻・反応）
  4. 約束（発言は保存しない・18歳以上・連絡先の交換はできない・AI店員と店主が見回る）
  5. 営業時間（毎晩21〜24時）とURL（`utm_source=note`）
  6. お願い（感想・お知らせの受け取り）
- 個人情報（本名・住所）は書かない。

| 見出し | 字数 |

| 既読のいらない飲み会、毎晩21時から | 17 |

- まずは上の2案でA/Bテストする（同じ予算・同じ画像で、見出しだけ変える）。比べるのは「広告から入店した割合」（H1）。
- 広告のURLは `utm_source=ads_x`（X広告）や `utm_source=ads_meta`（Instagram/Facebook）にし、`utm_content` に案の記号（`a`・`b`）を付ける。

## どこから来たか（URLの付け方）
PostHogで `page_view` を流入元ごとに分けて、入店率（H1）を比べる。**知人以外の流入で判断する**（`preopen` と `invite` は分けて見る）。

| 載せる場所 | URL |
|---|---|
| X（通常の投稿） | `https://yorunoba.onrender.com/?utm_source=x&utm_medium=social&utm_campaign=launch` |
| X広告 | `https://yorunoba.onrender.com/?utm_source=ads_x&utm_medium=paid&utm_campaign=launch&utm_content=a` |
| Instagram/Facebook広告 | `https://yorunoba.onrender.com/?utm_source=ads_meta&utm_medium=paid&utm_campaign=launch&utm_content=a` |
| note | `https://yorunoba.onrender.com/?utm_source=note&utm_medium=article` |
| Discord | `https://yorunoba.onrender.com/?utm_source=discord&utm_medium=community` |
| プレオープン（知人） | `https://yorunoba.onrender.com/?utm_source=preopen` |
| 店内の「誘う」ボタン | 自動で `utm_source=invite` が付く |
