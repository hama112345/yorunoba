# キャラクター（アバター）発注仕様書

ココナラ・SKIMA・Skeb などで絵師に依頼するときに、このページをそのまま渡す（またはURLを共有する）。

## 依頼の概要
- 用途：ブラウザで遊ぶ2Dのオンライン交流ゲーム「ヨルノバ」（夜の酒場で、テキストチャットで交流する）のプレイヤーキャラクター。
- 視点：**斜め見下ろし**（昔ながらの2D RPGのマップ視点）。背景の画像を参考として添付する。画風は背景に合わせてほしい。
- 頭身：**2.5頭身**のデフォルメキャラ。表情が見えるかわいさを重視。
- 雰囲気：夜の酒場でくつろぐ大人。服装は背景の方向性に合わせる。
  - 冒険者ギルドの酒場なら、軽装の冒険者・旅人風。
  - 大衆居酒屋なら、仕事帰りの私服・スーツ・作業着など。

## 体数
**見た目違いを6体**（できれば8体）。プレイヤーが入店時に1体を選ぶ。性別・髪型・服の色が偏らないようにしてほしい。

## アニメーション（1体あたり）
| 動き | 向き | コマ数の目安 |
|---|---|---|
| 待機（呼吸程度の小さな動き） | 下・上・左 | 各2〜4 |
| 歩き | 下・上・左 | 各4〜6 |
| 座り（椅子・座布団に座った姿） | 下・上・左 | 各1〜2 |

- 右向きは、左向きを左右反転してこちらで使う。非対称なデザイン（片側だけの髪飾りなど）は避けるか、右向きも別に用意してほしい。
- 余裕があれば：乾杯（ジョッキを掲げる）、手を振る、笑う、などの短い動きを各2〜4コマ（後日の追加でも可）。

## 納品形式
- **1コマ 64×64px**、背景透過のPNG。キャラの足元がコマの下から8px前後に来るようにそろえる。
- 1体につき1枚のスプライトシート。行＝動き×向き、列＝コマの順に並べる。
- 元データ（Aseprite / PSD など、レイヤーが分かれたもの）。
- 上の並び順を書いた簡単な表（どの行が何の動きか）。

## 権利・利用範囲（契約時に明記してほしいこと）
- 商用利用OK（ゲーム内での使用、課金要素を含むサービスでの使用）。
- 改変OK（色違いの作成、サイズ調整、コマの追加など）。
- 広告・SNS・告知画像・紹介動画での使用OK。
- 制作実績としての公開は、事前に相談のうえOK（公開前の秘密保持をお願いしたい）。
- 著作権の譲渡か、独占的な利用許諾かは、見積もり時に相談。

## スケジュール
- 希望納期：**D9**（一般公開の前日。日付は依頼時に記入）。
- 途中確認：ラフ（1体の正面・待機）の段階で一度見せてほしい。

## 参考
- 背景画像：選んだ1枚を添付する（`docs/art/background-prompts.md` で生成したもの）。
- ゲームの公開URL：https://yorunoba.onrender.com/ （仮の絵で動いている状態）

### オーナー向けメモ（絵師には渡さなくてよい）
- 発注の前に、背景の方向性（ギルドの酒場／大衆居酒屋／和風ファンタジー）を決めて1枚選んでおく。キャラの画風を背景に合わせるため。
- 見積もりは2〜3人から取り、ポートフォリオで「斜め見下ろしのドット絵キャラ」の実績がある人を選ぶ。
- 納品された絵はリポジトリ（`apps/client/public/assets/`）に置く。再配布や模倣を防ぐため、GitHubは非公開にしておくのがおすすめ。
- 届いたら、チャットに添付すればこちらで組み込む（`apps/client/src/assets.ts` に登録し、仮の丸いキャラと差し替える）。
