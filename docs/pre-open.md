# プレオープン（D7）の手順

知人5〜10人に、21時から30分〜1時間ほど遊んでもらい、致命的な問題がないかを確かめる。
ここで見つけた問題は、翌日（D8）に直してから一般公開（D10）に進む。

## 前日までにやること（オーナー）
| やること | どこで | 目安 |
|---|---|---|
| 公開中の店が最新になっているか確認 | GitHub Actions の「本番確認」が緑か（Claudeに聞けばOK） | 5分 |
| 店主の合言葉 `ADMIN_TOKEN` を設定 | Render → Environment | 5分 |
| AnthropicのAPIキー `ANTHROPIC_API_KEY` を設定 | Render → Environment。ログに「AI店員: 準備OK」が出るか見る | 10分 |
| PostHogのキー `VITE_POSTHOG_KEY` を設定 | PostHogでプロジェクトを作り、Render → Environment | 15分 |
| 事前登録フォームを作り `VITE_WAITLIST_URL` に設定 | Googleフォーム（質問は「メールアドレス」「ひとこと（任意）」だけでよい） | 15分 |
| Discordの通知先 `DISCORD_WEBHOOK_URL`（任意） | Discordのチャンネル設定 → 連携サービス → ウェブフック | 5分 |
| 規約・プライバシーポリシーの「お問い合わせ」を記入 | Claudeに連絡先（メールアドレスやフォーム）を伝える | 5分 |
| 無料プランのままでよいか決める | 当日だけなら無料でも可（最初の1人が入るまで1分ほど待つ）。気になるなら Starter（月7ドル） | — |

> 環境変数を保存するとRenderが自動で作り直す（数分）。`VITE_` で始まるものは画面の作り直しが必要なので、保存後のデプロイが終わってから確認する。

## 声のかけ方（例）
> 居酒屋っぽい雰囲気で、知らない人ともテキストでゆるく話せるWebサービスを作っています。
> 今夜21時から30分くらい、スマホで覗いてもらえませんか？登録なしでURLを開くだけです。
> https://yorunoba.onrender.com/?utm_source=preopen
> （名前はニックネームでOK。終わったら感想を3つだけ聞かせてください）

URLの `?utm_source=preopen` で、プレオープンから来た人を一般公開の人と分けて数えられる。
