## 数え方（PostHog）
- **H1**：ファネル `page_view` → `room_joined`。流入元（`utm_source`）で分ける。`preopen` と `invite` は知人として別に見る。
- **H2**：ファネル `room_joined` → `chat_sent`（`nth = 1`）。
  - あわせて `toast_sent`（乾杯）と `emote_sent`（反応）も見る。話さなくても参加した人の割合が分かる。
- **H3**：`room_left` の `seconds` の平均と中央値。
  - `via`（checkout／close／lost）で分けて、接続切れ（lost）が多すぎないかも見る。
- **H4・H4'**：リテンション（`room_joined` を起点、日単位）。端末ごとに数えるので、同じ人の別端末は別人になる点に注意。
- **H5**：事前登録フォームの回答数。`waitlist_clicked` はフォームを開いた数。
- **H6**：`paywall_clicked` の人数 ÷ `room_joined` の人数。`paywall_answered` の答えの分布（払わない／〜300円／480円ならアリ／もっと払える）も載せる。
- **H6'**：Stripeの支払い件数。`keep_bottle_clicked`（押した数）と並べる。
- **お会計の答え**：`exit_survey` の `answer` の分布。
- **話すきっかけの効き目**：お題を見た（`topic_viewed`）人と見ていない人で、発言した割合を比べる。
