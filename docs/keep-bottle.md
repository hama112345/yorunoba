# キープボトル（本当にお金を払うかの検証・H6'）

「常連パス」は押した数だけを数える“偽ドア”。キープボトルは**本当に500円を払ってもらう**ことで、支払い意思を確かめる。
コード側の準備はできていて、下の設定を入れるまで画面には出ない。

## 何が起きるか
1. 店内右上の「🎫 常連パス」のカードに「🍶 いま入れられます：キープボトル 500円」が出る（`VITE_KEEP_BOTTLE_URL` があるときだけ）。
2. 押すと、StripeのPayment Link（決済画面）が別タブで開く。計測は `keep_bottle_clicked`。
3. 支払いが終わったら、店主がStripeの画面で名前を確かめ、Renderの環境変数 `KEEP_BOTTLES` に足す。
4. 店の奥の酒棚の瓶に、その名前の縦書きの札が掛かる（最大8本）。常連パスのカードにも「棚のキープボトル：…」と出る。

DB・ログインは使わない（PoCの範囲外のため）。名前の管理は `KEEP_BOTTLES` の1行だけ。

## 始める前に（オーナー・30分ほど）
1. **特定商取引法の表記を埋める**：`apps/client/public/tokushoho.html` の「（準備中）」（販売事業者・運営責任者・お問い合わせ先）を、Claudeに伝えて埋めてもらう。
   - 個人の場合、所在地と電話番号は「請求があれば遅滞なく開示」のままでよい（いまの書き方）。
   - 埋まるまでは販売しない（ページにもそう書いてある）。
2. プライバシーポリシーの「お問い合わせ」も同じ連絡先で埋める。
3. **Stripeのアカウント**を作る（本人確認と銀行口座の登録まで）。

## Payment Link の作り方（Stripe）
1. Stripeのダッシュボード →「Payment Links」→「新規作成」。
2. 商品：名前「キープボトル（ヨルノバ）」、価格 **500円**、1回払い。
3. 「カスタムフィールドを追加」→ テキスト、ラベル「棚に掛ける名前（12文字まで）」、必須。
4. 「メールアドレスを収集」をオン（領収書と、名札を掛けられないときの連絡のため）。
5. 支払い後の画面：「確認ページを表示」→「ご購入ありがとうございます。3日以内に、店の酒棚にお名前の札を掛けます」。
6. 作成したリンク（`https://buy.stripe.com/...`）をコピーする。

## 画面に出す
1. Renderのサービス →「Environment」→ `VITE_KEEP_BOTTLE_URL` に、さっきのリンクを入れて保存する。
   - `VITE_` で始まる変数は画面の作り直しが要る。保存後のデプロイが終わってから確かめる。
2. スマホで店に入り、「🎫 常連パス」→「キープボトルを入れる」でStripeの画面が開くことを確かめる。
   - テストモードのリンクで先に試すと安心（テスト用のカード番号で払える）。

## 買ってくれた人の名札を掛ける
1. Stripeの「支払い」で新しい支払いを開き、カスタムフィールドの名前を見る。
2. 利用規約に反する名前・なりすましは掛けない（その場合は返金して、メールで知らせる）。
3. Renderの「Environment」→ `KEEP_BOTTLES` に、カンマ区切りで足す（例：`たろう,みさき`）。保存すると数分で店に反映される。
   - 名前は入店時と同じルールで整える（12文字まで）。札に見えるのは4文字まで（5文字以上は「…」）。
   - 棚に掛かるのは8本まで。9本目からは、常連パスのカードの一覧にだけ出る（8本を超えたらClaudeに棚を増やしてもらう）。

## 数え方（H6'）
- 本当に払った人数：Stripeの支払い件数（合格ライン：5件以上）。
- 押した人数：PostHogの `keep_bottle_clicked`（払わずに戻った人も含む）。
- 払った人の割合：支払い件数 ÷ 入店者数。常連パスの `paywall_clicked` と並べて見る（“押す”と“払う”の差を見る）。

## やめるとき
`VITE_KEEP_BOTTLE_URL` を消して保存すれば、ボタンは消える（デプロイ後）。Stripeの Payment Link も無効にしておく。
